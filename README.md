# Orquestador Test

Proyecto experimental de arquitectura multiagente utilizando Claude Cowork.

## Objetivo

Validar una arquitectura:

Usuario
↓
Agente Supervisor
↓
Agente Especialista
↓
Validación
↓
Respuesta final


## Agentes actuales

### Supervisor

Responsable de analizar solicitudes, decidir delegación y validar resultados.

### Redactor

Especialista en creación y mejora de comunicaciones escritas.
